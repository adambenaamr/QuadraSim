# QuadraSim

A quadtree is a type of tree in which each node has four children. It is a 2D variation of an octree and is most frequently used to divide a 2D space into smaller pieces by dividing a section into four parts.

This logic is rather simple, if the quadrant has a node (point) inside it then break it into 4 more quadratns. Rinse and repeat.
